### 🟠 H1: رقم المستند الجديد — لا يُعرَض بعد الحفظ
النظام يُولِّد الرقم في الباكاند لكن المودال يُغلَق بعد 1.5 ثانية دون إعلام

**الحل:** عرض رقم المستند المُنشأ في رسالة النجاح + نسخه للحافظة تلقائياً:
```tsx
onSuccess: (savedDoc) => {
  const docNum = String(savedDoc.document_number ?? '—');

  navigator.clipboard?.writeText(docNum).catch(() => {});
  // إبقاء المودال مفتوحاً 3 ثوانٍ لعرض الرقم
}
```

## ══ النقاط التحسينية (Medium) — من ERP الكبار ══════════════════════════

### 🟡 M1: لا Proforma حقيقي في الباكاند (مخاطرة)
`is_proforma` موجود في الفرونتند لكن confirmProformaMut يُرسل فقط:
```tsx
apiPut(`/documents/${id}`, { is_proforma: false });
```
في SAP: تحويل Pro Forma لفاتورة حقيقية يُنشئ:
- VF01 (Billing Document)
- حركات المخزون (التسليم الفعلي)
- قيود المحاسبة (Accounting Entries)

**الخطر الحالي:** تحويل Pro Forma لا يُنشئ حركة مخزون!
**الحل:** endpoint مخصص `POST /documents/{id}/confirm-proforma` في الباكاند
يُنفِّذ كل العمليات داخل transaction واحدة.

### 🟡 M2: تحويل المستندات (CONVERSION_MAP) — بدون حماية مزدوجة
```tsx
// المودال يسمح بتحويل BL → FV
```
